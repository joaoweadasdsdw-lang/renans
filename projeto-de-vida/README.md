# Projeto de Vida - Dashboard Web

Este é um projeto web completo, interativo e editável para organização do **Projeto de Vida**, desenvolvido em HTML, Tailwind CSS e JavaScript puro.

## 🚀 Como usar no VS Code:

1. Extraia o conteúdo deste arquivo `.zip` em qualquer pasta do seu computador.
2. Abra a pasta no **VS Code**.
3. Abra o arquivo `index.html`.
4. Clique com o botão direito no `index.html` e selecione **Open with Live Server** (se tiver a extensão instalada) ou simplesmente dê dois cliques no arquivo `index.html` para abri-lo direto no seu navegador.

## ✨ Recursos:
- **Totalmente Editável**: Clique no Nome, Profissão ou Declaração de Propósito direto na tela para editar.
- **Metas por Prazo**: Gerencie objetivos de Curto, Médio e Longo prazo.
- **Barra de Progresso**: Atualização automática conforme marca as metas concluídas.
- **Habit Tracker**: Marque hábitos diários.
- **Vision Board**: Adicione cards de inspiração e imagens por URL.
- **Persistência**: Tudo é salvo automaticamente no seu navegador (`localStorage`).
