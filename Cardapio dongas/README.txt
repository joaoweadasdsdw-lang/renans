# Sistema de Cardápio e Presença — CEM Dom Ungarelli

## Arquivos
- `index.html` — página principal
- `css/style.css` — estilos
- `js/app.js` — cadastro, presença, cardápio, filtros e exportação
- `img/logo-dom-ungarelli.jpeg` — logo fornecida

## Como usar no VS Code
1. Extraia a pasta.
2. Abra a pasta no VS Code.
3. Abra `index.html`.
4. Se tiver a extensão Live Server, clique com o botão direito em `index.html` e escolha **Open with Live Server**.

## Recursos
- 3 refeições: café da manhã, almoço e lanche.
- Cardápio editável por data.
- Cadastro de alunos e turmas.
- Registro de presença separado por refeição e data.
- Busca e filtro por turma.
- Resumo automático das presenças.
- Exportação dos registros em CSV.
- Dados salvos no navegador com `localStorage`.

## Horários das refeições
- 1ª refeição — 09:10h
- 2ª refeição (almoço) — 12:00h
- 3ª refeição (lanche da tarde) — 15:00h
